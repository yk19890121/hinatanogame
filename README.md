# マッチョ さんすうラン！

ひなたの ゲーム。マッチョな ヒーローと いっしょに はしって、**ひとけたの たしざん・ひきざん** で かべを こわしていく よこスクロール アクションです。

- 正解すると マッチョが ダブルバイセップスで ポーズ → パンチで いしの かべを こわし、金色の「マッスルパワー」状態に
- 問題は 声で 読み上げ（🔊ボタンで もう一度）、数を ●で 数えられる ヒントつき
- まちがえても ペナルティなし（その ブロックが 石になって、残りから 選べる）
- 各ステージの さいごに ボス（3もん 正解で たおせる）

## あそびかた

| そうさ | キーボード | タブレット・スマホ |
| --- | --- | --- |
| いどう | ← → （A / D） | 左下の ◀ ▶ |
| ジャンプ | スペース / ↑ / Z | 右下の ジャンプ |
| ひとやすみ | Esc / P | 右上の ボタン |

ゲームパッド（Xbox / PlayStation コントローラー）も そのまま 使えます。

**こたえかた**: もんだいが 出たら、こたえの 数字ブロックの 下に 行って ジャンプで 頭突き！

## おうちの人むけ せってい（タイトルの ⚙）

- **かずの おおきさ**: 5まで / 10まで（初期値） / 18まで — たし算の答え・ひき算の最初の数の上限。式に出る数は いつも ひとけた（1〜9）です
- **よみあげ こえ**: ブラウザの日本語音声で問題を読み上げ（Windows / Mac / iPad / Android の標準音声で動きます）
- **かぞえる ●ヒント** / **おんがく** / **こうかおん**: オン・オフ

設定と ★の記録は その端末の ブラウザに 保存されます。

## 起動のしかた

ビルドも インストールも 不要です。画像ファイルは マッチョと ボスの 2枚（`assets/`）だけで、背景・問題カード・数字ブロック・音は すべてプログラムで その場で 描いて（鳴らして）います。

※ `index.html` を ダブルクリックで 開いた場合、ブラウザの 制限で「ステージを えらぼう」の 小さな 絵が 色だけの 表示に なります（ゲーム本体は ふつうに 遊べます）。GitHub Pages など URL で 開けば 絵も 出ます。

- **パソコン**: `index.html` を ダブルクリックで ブラウザ（Chrome / Edge 推奨）で開く
- **タブレット・スマホで遊ぶ**: GitHub Pages で 公開すると URL で 開けます
  1. GitHub の リポジトリ → **Settings** → **Pages**
  2. Source を **Deploy from a branch**、Branch を **main** / **/(root)** にして Save
  3. 1〜2分後に `https://yk19890121.github.io/hinatanogame/` で 遊べます
  4. iPad / iPhone は 共有 → 「ホーム画面に追加」で 全画面アプリのように 遊べます

文字（丸ゴシック）は Google Fonts から 読み込みます。オフラインでも 端末の フォントで 遊べます。

## ファイル構成

```
index.html        がめんの わくぐみ（メニュー・もんだいパネル・タッチボタン）
assets/hero.webp  マッチョの アニメ（6列×5段 30コマ、足元中央で 位置合わせ済み）
assets/boss.webp  ボスの アニメ（6列×5段 30コマ、体の底の中央で 位置合わせ済み）
js/sprite-meta.js 上の 2枚の コマの 大きさと 基準点（ツールが 自動生成）
js/sprites.js     状態ごとの コマ割り当て（待機・歩く・ジャンプ・落下・着地・ポーズ…）
tools/process_sprites.py  キャラ画像の 背景除去・コマ分割・位置合わせ ツール
css/style.css     メニューや もんだいパネルの みため
js/util.js        共通の 道具（定数・乱数・色）
js/quiz.js        さんすう問題の 作成（答えの近くの数を 選択肢に）
js/audio.js       効果音・BGM（その場で合成）・読み上げ
js/input.js       キーボード・タッチ・ゲームパッド
js/themes.js      4つの世界の 背景の 描き方と 色
js/assets.js      地面・ブロック・かざりの 絵を 先に 描いておく
js/hero.js        マッチョ（骨組みアニメーション と 筋肉の 描画）
js/entities.js    スライム・ボス・数字ブロック・かべ・アイテム・エフェクト
js/level.js       当たり判定 と ステージの 自動生成（毎回 同じ形）
js/render.js      画面の 描画（空・パララックス・地面・光）
js/ui.js          HTML の ボタンや 表示
js/game.js        ゲームの 進行（問題・カメラ・ボス・クリア）
```

### かんたんな 改造ポイント

- マッチョの ほめ言葉: `js/game.js` の `PHRASES`
- ステージの 名前・問題の種類（`ops: ['+']` など）: `js/themes.js` の `STAGES`
- マッチョ / ボスの 表示の 大きさ: `js/hero.js` の `HERO_SPRITE_S` / `js/sprites.js` の `BOSS_SPRITE_S`
  （当たり判定は 絵とは 別。マッチョを 大きくしすぎると 数字ブロックの 下を 通れなくなるので 注意）
- どの 状態で どの コマを 使うか: `js/sprites.js` の `HERO_ANIM` / `BOSS_ANIM`

### キャラ画像を 差し替えるとき

同じ 6列×5段・同じ 並び（マッチョ: 待機/歩行/ジャンプ/落下・着地/ポーズ、ボス: 待機/弾む/突進/ダメージ/撃破）の シートを 用意して:

```
pip install pillow numpy
python tools/process_sprites.py マッチョの画像.webp ボスの画像.webp
```

背景の 透過処理、30コマの 分割（隣の キャラが 混ざっていないか・はみ出しが ないかも チェック）、位置合わせを して `assets/` と `js/sprite-meta.js` を 作り直します。確認用の 画像は `tools/out/` に 出ます。
