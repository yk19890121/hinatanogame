# マッチョ さんすうラン！

ひなたの ゲーム。マッチョな ヒーローと いっしょに はしって、**たしざん・ひきざん** で かべを こわしていく よこスクロール アクションです。

- **むずかしさ 5段階 × ステージ 4つ = 20とおり**（ひとけた 〜 110まで）
- 正解すると 正解ボイス → **マッチョの カットイン ＋ おうえんボイス**（通常 40体・**レア 5体**。レアは 10％で 専用の 演出）→ パンチで いしの かべを こわし、金色の「パワー全開」状態に
- 問題は 声で 読み上げ（🔊ボタンで もう一度）。数を かぞえる ヒントつき（9までは ●、10いじょうは 10の ぼう・100の しかく の まとまり）
- まちがえても ペナルティなし（その ブロックが 石になって、残りから 選べる）
- 各ステージの さいごに ボス（3もん 正解で たおせる。攻撃が 当たって 約1秒で 次の 問題）
- ダンベルを 10・20・35こ 取るたびに 声援（35こで 1周して くりかえし）、プロテインを 取ると「ハイ、ここでプロテイン」
- ゴールすると、そのステージで 出た 問題の 一覧（さいしょの 答えで 正解は ○、まちがえてから 正解は × → ○）
- BGM は 17曲から ランダム（切りかえ・ループは 0.5秒 フェードイン／2秒 フェードアウトで 重ねる。ゴール後は クリアの 曲を ステージえらびまで そのまま）

公開URL: https://yk19890121.github.io/hinatanogame/

## むずかしさ と ステージ

「ステージを えらぼう」の 上の「むずかしさ」で えらびます（ぜんぶ 最初から えらべます）。えらんだ むずかしさは 次に 開いたときも おぼえています。

| むずかしさ | 上限 | ふだんの 出題（たし算の答え／ひき算の ひかれる数） |
| --- | ---: | --- |
| レベル1：1けた | 9 | 2〜9 |
| レベル2：19まで | 19 | 10〜19 |
| レベル3：39まで | 39 | 20〜39 |
| レベル4：79まで | 79 | 40〜79 |
| レベル5：110まで | 110 | 80〜110 |

| ステージ | 世界 | 計算 |
| --- | --- | --- |
| 1 | あさの くさはら | たし算 100％ |
| 2 | ゆうやけ さばく | ひき算 100％ |
| 3 | オーロラの ゆきやま | たし算 70％・ひき算 30％ |
| 4 | よぞらの ネオンシティ | たし算 30％・ひき算 70％ |

- 問題・答え・選択肢は すべて 0〜上限の 中。マイナスや 小数は 出ません（ひき算の 答え 0 は 出ることが あります）
- 3つの ブロックには 正解が かならず 1つ、数字の 重なりなし、正解の 位置は ランダム
- ★は「むずかしさ × ステージ」ごとに 記録（ほかの むずかしさの 記録は 上書きしません）
- 割合の 変更: `js/quiz.js` の `STAGE_MIX`、数の 範囲: 同じく `LEVELS`

## 起動のしかた

ビルドも インストールも 不要です。

- **タブレット・スマホ**: 上の 公開URL を 開く。iPad / iPhone は 共有 →「ホーム画面に追加」で 全画面アプリのように 遊べます
- **パソコン**: 公開URL、または `index.html` を ブラウザ（Chrome / Edge 推奨）で開く

※ `index.html` を ダブルクリックで 開いた場合、ブラウザの 制限で「ステージを えらぼう」の 小さな 絵が 色だけに なります（ゲーム本体は 遊べます）。

※ 音は ブラウザの きまりで、最初に「あそぶ」などを タップした あとから 鳴ります。

- 曲の 切りかえ: 前の曲を **2秒**で フェードアウト しながら、新しい曲を すぐ **0.5秒**で フェードイン（無音の すきま なし）。前の曲は はじめ 早めに 下げるので、2曲 重なっても 大きく なりすぎません

- 重なるのは 2曲まで（すばやく 画面を 行き来しても 3曲めが 来たら いちばん古い 曲を すぐ止めます）
- 声援・読み上げ・レア演出の あいだは BGM 全体を 少し 下げます（曲ごとの フェードとは 別の つまみ なので ぶつかりません）

## クリア画面の 問題一覧

ゴールすると、そのステージで 出た 問題（道中と ボス）を 出た 順に 「3 ＋ 2 ＝ 5」のように 答えまで 入れて 表示します。ボスの 問題には 小さく「ボス」。

| 答えかた | 表示 |
| --- | --- |
| さいしょの 答えで 正解 | ○ |
| 1回いじょう まちがえて、そのあと 正解 | × → ○ |

同じ 問題への やり直しは 1行に まとめ、別の 出題で 同じ 式が 出た ときは 別の 行に なります。記録は 落ちて もどっても 消えず、次の ステージ・さいしょから で 消えます。一覧が 長いときは 一覧の 中だけ スクロールします（★の 基準は 以前と 同じ）。

### 正解の キャラの 出かた

- 正解の たびに まず「通常 90％ ／ レア 10％」を 抽選（レア 5体 ぜんたいで 10％）。出現率は `js/cutin.js` の `RARE_RATE` 1か所で 変えられます
- 通常は 40体、レアは 5体の 中から、それぞれ シャッフルして 順番に（同じ キャラは 続きません）。道中・ボス、むずかしさ・ステージに 関係なく 同じ ルール
- 開発用: URL に `?rare=1`〜`?rare=5` で その レアを 毎回（1=巨大ロボ 2=神 3=黄金マッチョ 4=高層ビルマッチョ 5=銀のゴリラ）、`?rare=all` で 毎回 レア、`?rare=normal` で レアなし

### レア演出

正解ボイス → **少し 暗く（黒い 半透明 45％・0.2秒）＋ ほら貝** → 0.15秒後に **マッスル群の 動画**（3.667秒・等倍・動画の 音つき）→ 動画の 最後の 0.25秒で 画面を 明るく 戻しながら 動画を 消し、同時に **レアの 画像が スライドイン ＋ ドーン ＋ セリフ**（ほら貝の 余韻は 0.2秒で 消す）→ セリフが 終わったら スライドアウト → 壁・ボスへの 攻撃（1回）

- 動画は 緑背景を ぬいて（`tools/process_muscle.py`）、画面の 上に いちばん 前で 表示（たてよこの わりあいは そのまま、はみださない）。だれも いない 最初の 9コマは 音ごと けずっています
- 動画の 音は 別の 効果音として 動画と 同時に 鳴らします（iPhone でも 鳴らせる ように。設定は「こうかおん」）
- セリフは「よみあげ こえ」、ほら貝・ドーン・動画の 音は「こうかおん」。オフでも 映像は 最後まで 進みます
- 演出中は 敵・ボス・ゲームの 進行・パワーの 残り時間が 止まります。ひとやすみで 動画と 音も 止まり、再開で 続きから
- やりなおし・画面移動で 動画・音・タイマーを 全部 止めます（あとから 攻撃や 音が 出ません）
- 動画を 読みこめない・すかして 出せない ときは 0.45秒で 画像の 登場へ 進みます

### 素材を 作り直す ツール

```
pip install pillow numpy imageio-ffmpeg
python tools/process_muscle.py マッスル群.MP4                         # 動画の 緑背景を ぬく → assets/video/muscle.mp4・音は assets/sfx/muscle.mp3（等倍。--speed 3 で 3倍速）
python tools/build_media.py --bgm <「BGM・SE」フォルダ> <素材フォルダ> ...   # BGM候補の 登録と 音量そろえ・音の コピー（元は source/voice/、前後の 無音を けずった ゲーム用は assets/voice/）・js/media.js・元画像の 保管
python tools/trim_voices.py                                        # 声の はじまり・おわり の 位置を ひょうじ（けずる 位置の 確認）
python tools/fix_cutin3.py source/cutin/本気の背中と爆発的な文字-3.png source/cutin_edit/本気の背中と爆発的な文字-3_できるぞ.png
python tools/process_cutins.py source/cutin source/cutin_edit [番号 ...]  # 緑背景の 除去 → assets/cutin/（番号を つけると その キャラだけ）
python tools/process_sprites.py マッチョの画像.webp ボスの画像.webp     # キャラの コマ分割
```

確認用の 画像（明るい背景・暗い背景に 重ねた 一覧など）は `tools/out/` に 出ます。
