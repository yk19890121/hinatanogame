# マッチョ さんすうラン！

ひなたの ゲーム。マッチョな ヒーローと いっしょに はしって、**たしざん・ひきざん** で かべを こわしていく よこスクロール アクションです。

- **むずかしさ 5段階 × ステージ 4つ = 20とおり**（ひとけた 〜 110まで）
- 正解すると 正解ボイス → **マッチョの カットイン ＋ おうえんボイス**（20種類）→ パンチで いしの かべを こわし、金色の「パワー全開」状態に
- 問題は 声で 読み上げ（🔊ボタンで もう一度）。数を かぞえる ヒントつき（9までは ●、10いじょうは 10の ぼう・100の しかく の まとまり）
- まちがえても ペナルティなし（その ブロックが 石になって、残りから 選べる）
- 各ステージの さいごに ボス（3もん 正解で たおせる）
- ステージごとの BGM（ステージえらび・クリア画面にも 専用の 曲）

公開URL: https://yk19890121.github.io/hinatanogame/

## あそびかた

| そうさ | キーボード | タブレット・スマホ |
| --- | --- | --- |
| いどう | ← → （A / D） | 左下の ◀ ▶ |
| ジャンプ | スペース / ↑ / Z | 右下の ジャンプ |
| ひとやすみ | Esc / P | 右上の ボタン |

ゲームパッド（Xbox / PlayStation コントローラー）も そのまま 使えます。

**こたえかた**: もんだいが 出たら、こたえの 数字ブロックの 下に 行って ジャンプで 頭突き！（1回の ジャンプで 答えられるのは 1回だけ）

## むずかしさ と ステージ

「ステージを えらぼう」の 上の「むずかしさ」で えらびます（ぜんぶ 最初から えらべます）。えらんだ むずかしさは 次に 開いたときも おぼえています。

| むずかしさ | 上限 | ふだんの 出題（たし算の答え／ひき算の ひかれる数） |
| --- | ---: | --- |
| レベル1：1けた | 9 | 2〜9 |
| レベル2：19まで | 19 | 10〜19 |
| レベル3：39まで | 39 | 20〜39 |
| レベル4：79まで | 79 | 40〜79 |
| レベル5：110まで | 110 | 80〜110 |

| ステージ | 世界 | 計算 | BGM |
| --- | --- | --- | --- |
| 1 | あさの くさはら | たし算 100％ | お願いマッスル |
| 2 | ゆうやけ さばく | ひき算 100％ | マッチョメン |
| 3 | オーロラの ゆきやま | たし算 70％・ひき算 30％ | ボンジョビ |
| 4 | よぞらの ネオンシティ | たし算 30％・ひき算 70％ | アイオブザタイガー |

- 問題・答え・選択肢は すべて 0〜上限の 中。マイナスや 小数は 出ません（ひき算の 答え 0 は 出ることが あります）
- 3つの ブロックには 正解が かならず 1つ、数字の 重なりなし、正解の 位置は ランダム
- ★は「むずかしさ × ステージ」ごとに 記録（ほかの むずかしさの 記録は 上書きしません）
- 割合の 変更: `js/quiz.js` の `STAGE_MIX`、数の 範囲: 同じく `LEVELS`

## おうちの人むけ せってい（タイトルの ⚙ ／ ひとやすみ中の せってい）

| 設定 | 対象 |
| --- | --- |
| おんがく | BGM（ステージえらび・ステージ1〜4・クリア画面） |
| よみあげ こえ | イベントボイス・おうえんボイス・問題の 読み上げ（オフでも カットインの 絵は 出ます） |
| こうかおん | 花火の 音・ジャンプ・パンチ などの 効果音 |
| かぞえる ●ヒント | 問題カードの ●・まとまり 表示 |

設定と ★の記録は その端末の ブラウザに 保存されます。以前の 版の ★の記録は `macho_progress_v1_backup` として 残してあります（どの むずかしさか わからないため 新しい 記録には 移していません）。

## 起動のしかた

ビルドも インストールも 不要です。

- **タブレット・スマホ**: 上の 公開URL を 開く。iPad / iPhone は 共有 →「ホーム画面に追加」で 全画面アプリのように 遊べます
- **パソコン**: 公開URL、または `index.html` を ブラウザ（Chrome / Edge 推奨）で開く

※ `index.html` を ダブルクリックで 開いた場合、ブラウザの 制限で「ステージを えらぼう」の 小さな 絵が 色だけに なります（ゲーム本体は 遊べます）。

※ 音は ブラウザの きまりで、最初に「あそぶ」などを タップした あとから 鳴ります。

## ファイル構成

```
index.html            がめんの わくぐみ（メニュー・問題カード・カットイン・タッチボタン）
css/style.css         メニュー・問題カード・カットインの みため
assets/hero.webp      マッチョの アニメ（6列×5段 30コマ）
assets/boss.webp      ボスの アニメ（6列×5段 30コマ）
assets/cutin/         正解カットインの 画像 20枚（透過WebP）
assets/bgm/ sfx/ voice/  音（上の 対応一覧）
source/               素材の 元画像（ゲームでは 読み込まない）
js/media.js           音・画像の 一覧（ID・パス・セリフ・元ファイル名・長さ）
js/sprite-meta.js     キャラの コマの 大きさと 基準点
js/util.js            共通の 道具（定数・乱数・色）
js/quiz.js            むずかしさ（LEVELS）・ステージの 計算割合（STAGE_MIX）・問題と 選択肢の 作成
js/audio.js           効果音・タイトルの 曲（その場で 合成）
js/media-audio.js     BGM（1曲だけ）・ボイス（順番に 1本ずつ）・花火の 音
js/input.js           キーボード・タッチ・ゲームパッド
js/themes.js          4つの世界の 背景と ステージの 地形
js/assets.js          地面・ブロック・かざりの 絵
js/sprites.js         状態ごとの コマ割り当て（待機・歩く・ジャンプ・落下・着地・ポーズ…）
js/hero.js            マッチョ（動き・当たり判定）
js/entities.js        スライム・ボス・数字ブロック・かべ・アイテム・エフェクト
js/level.js           当たり判定 と ステージの 自動生成（毎回 同じ形）
js/render.js          画面の 描画（空・パララックス・地面・光）
js/cutin.js           正解カットイン（画像と ボイスの ペア選び・スライドイン/アウト）
js/ui.js              HTML の ボタンや 表示（むずかしさ・ヒント・クリア画面）
js/game.js            ゲームの 進行（問題・カメラ・ボス・クリア・記録）
tools/                素材を 作り直す ツール（下記）
```

### 素材を 作り直す ツール

```
pip install pillow numpy
python tools/build_media.py <素材.zipを 展開した フォルダ>         # 音の コピー・js/media.js・元画像の 保管
python tools/fix_cutin3.py source/cutin/本気の背中と爆発的な文字-3.png source/cutin_edit/本気の背中と爆発的な文字-3_できるぞ.png
python tools/process_cutins.py source/cutin source/cutin_edit         # 緑背景の 除去 → assets/cutin/
python tools/process_sprites.py マッチョの画像.webp ボスの画像.webp     # キャラの コマ分割
```

確認用の 画像（明るい背景・暗い背景に 重ねた 一覧など）は `tools/out/` に 出ます。

### 更新するとき

ブラウザに 古い ファイルが 残らないように、`index.html` の `?v=20261027` を 新しい 日付に 変えてから push してください（音や 画像は 名前が 変わるときだけ 気にすれば OK）。
