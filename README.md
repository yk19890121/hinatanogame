# マッチョ さんすうラン！

ひなたの ゲーム。マッチョな ヒーローと いっしょに はしって、**たしざん・ひきざん** で かべを こわしていく よこスクロール アクションです。

- **むずかしさ 5段階 × ステージ 4つ = 20とおり**（ひとけた 〜 110まで）
- 正解すると 正解ボイス → **マッチョの カットイン ＋ おうえんボイス**（通常 40体・**レア 5体**。レアは 30％で 専用の 演出）→ パンチで いしの かべを こわし、金色の「パワー全開」状態に
- 問題は 声で 読み上げ（🔊ボタンで もう一度）。数を かぞえる ヒントつき（9までは ●、10いじょうは 10の ぼう・100の しかく の まとまり）
- まちがえても ペナルティなし（その ブロックが 石になって、残りから 選べる）
- 各ステージの さいごに ボス（3もん 正解で たおせる。攻撃が 当たって 約1秒で 次の 問題）
- ダンベルを 10・20・35こ 取るたびに 声援（35こで 1周して くりかえし）、プロテインを 取ると「ハイ、ここでプロテイン」と ライフ ＋1（上限なし。3より 多くも なり、6いじょうは「♥ × 6」の ように 数で 表示。やりなおし・次の ステージで 3に もどる）
- ゴールすると、そのステージで 出た 問題の 一覧（さいしょの 答えで 正解は ○、まちがえてから 正解は × → ○）
- BGM は 17曲から ランダム（切りかえ・ループは 0.5秒 フェードイン／2秒 フェードアウトで 重ねる。ゴール後は クリアの 曲を ステージえらびまで そのまま）。プレイ中は 右上（ひとやすみの 下）の「♫ シャッフル」で 別の 曲へ（今と 同じ 曲は 選ばず、ひとまわり するまで くりかえしにくい 順番。先頭から。連打しても 0.4秒に 1回・重なるのは 2曲まで。ジャンプや 答えには なりません）
- ボスは **20ステージ ぜんぶ ちがう 20体**（各レベルの ステージ1・2=ボス、3=中ボス、4=ラスボス）
- レアキャラが 出ると **仲間に なって** うしろを ついてきて、正解の たびに いっしょに 攻撃
- タイトルで **通常モード ／ オトナモード** を えらべる（オトナは 2けたの 四則演算・ライフ3・1ステージ3分・ボスの 攻撃を ジャンプで よける）

## むずかしさ と ステージ

「ステージを えらぼう」の 上の「むずかしさ」で えらびます（ぜんぶ 最初から えらべます）。えらんだ むずかしさは 次に 開いたときも おぼえています。

| むずかしさ | 上限 | ふだんの 出題（たし算の答え／ひき算の ひかれる数） |
| --- | ---: | --- |
| レベル1：1けた | 9 | 2〜9 |
| レベル2：19まで | 19 | 10〜19 |
| レベル3：39まで | 39 | 20〜39 |
| レベル4：79まで | 79 | 40〜79 |
| レベル5：110まで | 110 | 80〜110 |

| ステージ | 世界 | 計算 |
| --- | --- | --- |
| 1 | あさの くさはら | たし算 100％ |
| 2 | ゆうやけ さばく | ひき算 100％ |
| 3 | オーロラの ゆきやま | たし算 70％・ひき算 30％ |
| 4 | よぞらの ネオンシティ | たし算 30％・ひき算 70％ |

- 問題・答え・選択肢は すべて 0〜上限の 中。マイナスや 小数は 出ません（ひき算の 答え 0 は 出ることが あります）
- 3つの ブロックには 正解が かならず 1つ、数字の 重なりなし、正解の 位置は ランダム
- ★は「むずかしさ × ステージ」ごとに 記録（ほかの むずかしさの 記録は 上書きしません）
- 割合の 変更: `js/quiz.js` の `STAGE_MIX`、数の 範囲: 同じく `LEVELS`

## モード（通常 ／ オトナ）

タイトルの「あそぶ」の 上で えらびます（開く たびに 通常モードから）。えらんだ モードは 色と 白い わくで 表示、ステージえらびの 見出しと プレイ中の 左上（オトナは のこり時間つき）にも 出ます。どちらも レベル1〜5 × ステージ4つ。

| | 通常モード（いままで どおり） | オトナモード |
| --- | --- | --- |
| 出題 | 上の「むずかしさ と ステージ」 | 下の 表（4ステージとも その レベルの 出題） |
| ライフ | ハート3（まちがいでは へらない。0で チェックポイントから やりなおし） | 3（0で ゲームオーバー） |
| まちがい・雑魚に 接触 | まちがい: なし ／ 接触: ハート −1 | それぞれ ライフ −1 |
| ボスの 攻撃 | なし | 約10秒に 1回（ジャンプで よける。当たると −1） |
| 制限時間 | なし | 1ステージ 180秒 |
| ボスの ライフ | 3 | レベル順に 4・5・6・7・8 |
| レア仲間 | いっしょに 攻撃（演出だけ。ダメージは 1） | いっしょに 攻撃して ＋1（正解1回で 2） |
| ★の 記録 | `macho_progress2`（いままでの まま） | `macho_progressAdult`（★と のこり時間の 最高） |

| オトナ | 出題（2けた=10〜99、1けた=1〜9） |
| --- | --- |
| レベル1 | 2けた ＋ 2けた |
| レベル2 | 2けた − 2けた（答えは 0 以上） |
| レベル3 | 2けた × 1けた |
| レベル4 | 2けた ÷ 1けた（わりきれる ものだけ） |
| レベル5 | ＋ − × ÷ を 4種類 順番に シャッフル（× は 2けた×2けた、÷ は 2けた÷2けた・わりきれる もの） |

オトナモードの きまり（数字は `js/chara.js` の `ADULT` で 変えられます）

- ライフが へるのは「まちがい（答えを 確定した 1回ごと）」「雑魚に 接触」「ボスの 弾に 当たる」と、穴に 落ちた とき。0 になった 時点で ゲームオーバー
- 接触・被弾の あとは 約1秒 点滅して 無敵（重なった ままでも 毎フレーム へらない）。無敵中でも 新しい まちがいは −1
- 問題の 答えを 確定した あとの 演出中（カットイン・攻撃）は 当たりません。動けるように なった 直後も 0.8秒は 接触・弾で へりません
- 回復の プロテインは 1こで ＋1（上限なし。4いじょうからも 1ずつ へる。「まだいける！」は 2に なった とき、「あと一回！」は 1に なった とき）
- 時間は 操作 できる ように なってから（ボスの 絵の 読みこみが 終わってから）実際の 経過時間で へります。カットイン・レア演出・仲間加入の あいだも 止まりません（ひとやすみ中は 止まる）。0 で 演出中でも 時間切れ。クリアが 決まった 時点で 止まります
- ボスの 攻撃: 最初の 問題が 出てから 約10秒で 1回め、そのあとは 発射から 約10秒ごと。発射の 0.8秒前に 予告の 音（毎回）＋ ボスが 赤く 光って「！」（「攻撃が来るぞ！」の 声は ときどき）。弾は 地面すれすれを 左へ（ジャンプで 越えられる 高さ）
- カットイン中・答えの 演出中・ダメージ中 など ジャンプ できない あいだは 予告も 発射も しません（たまった 分を まとめて 撃たない）。動けるように なって 1秒 たってから あらためて 予告して 1回だけ。答えを 確定した とき 飛んでいる 弾は 消えます
- 予告から 弾が ヒーローの 前を 通りすぎる まで、数字ブロックを 頭で たたいても 答えに なりません（よける ジャンプで うっかり 答えない。ミスにも なりません）
- ボスを たおした・ゲームオーバー・時間切れ・ステージを はなれた ときは 弾・攻撃タイマー・予約を ぜんぶ 消します
- ゲームオーバー／時間切れの 画面から「もういちど」で ライフ3・180秒・仲間なしで やりなおし

## 起動のしかた

ビルドも インストールも 不要です。

- **タブレット・スマホ**: 上の 公開URL を 開く。iPad / iPhone は 共有 →「ホーム画面に追加」で 全画面アプリのように 遊べます
- **パソコン**: 公開URL、または `index.html` を ブラウザ（Chrome / Edge 推奨）で開く

※ `index.html` を ダブルクリックで 開いた場合、ブラウザの 制限で「ステージを えらぼう」の 小さな 絵が 色だけに なります（ゲーム本体は 遊べます）。

※ 音は ブラウザの きまりで、最初に「あそぶ」などを タップした あとから 鳴ります。

### レア演出

正解ボイス → **少し 暗く（黒い 半透明 45％・0.2秒）＋ ほら貝** → 0.15秒後に **マッスル群の 動画**（4秒・等倍・カット なし・動画の 音つき）→ 動画に だれかが 映っている 最後の 0.25秒（3.55〜3.80秒。そのあとの 0.2秒は 何も 映っていない コマ）で 動画を 消し、同時に **レアの 画像が スライドイン ＋ 登場の 音（教会の祈り）＋ セリフ**（ほら貝の 余韻は 0.2秒で 消す）。画像の あいだは **通常キャラと 同じ 暗さ**（動画の 黒い 幕から 通常の 幕へ 0.25秒で 引きつぐ）→ セリフが 終わったら スライドアウト しながら 明るく 戻す → **そのキャラが 仲間に なる**（加入SE ＋ 本人の 加入セリフ。セリフは ゲームを 止めずに 流す）→ 壁・ボスへの 攻撃（1回）

- 画面の 上に、暗く する 幕・HUD・問題より 前で 表示（動画は 暗く しない。たてよこの わりあいは そのまま、はみださない）。動画は 960×540・30コマ/秒に して 読みこみを 軽く しています
- 一時停止で 動画と 音を いっしょに 止め、再開は 音が 動きだすのに そろえて 動画も 続きから
- 動画の 音は 別の 効果音として 動画と 同時に 鳴らします（iPhone でも 鳴らせる ように。設定は「こうかおん」）

- 演出中は 敵・ボス・ゲームの 進行・パワーの 残り時間が 止まります。ひとやすみで 動画と 音も 止まり、再開で 続きから

- 動画を 読みこめない・すかして 出せない ときは 0.45秒で 画像の 登場へ 進みます

## レア仲間（ZIP「レアキャラデータ」）

| レアの カットイン | 仲間 | 画像 | 弾 |
| --- | --- | --- | --- |
| 全身が純金！まぶしすぎる！ | 黄金マッチョ | `assets/ally/R01_gold.png` | 黄金の 拳弾 |
| デカすぎる！筋肉、超巨大ロボ級！ | 巨大筋肉ロボ（小さい 人物なしの 仲間用 素材） | `assets/ally/R02_robot.png` | 紫の 光弾 |
| ムキムキじゃないのに、神レベル！ | 雲乗りの神様（雲に 乗って ういている） | `assets/ally/R03_god.png` | 金色の 雷 |
| 銀のゴリラ！筋肉も規格外！ | 銀のゴリラ | `assets/ally/R04_gorilla.png` | 青白い 衝撃波 |
| 肩の上に高層ビル、建ってるよ！ | 高層ビルマッチョ | `assets/ally/R05_tower.png` | ビルの 拳弾 |

- 14コマ（加入2・待機2・移動4・攻撃4・ジャンプ2）を `ally_manifest.json` の とおりに。向きは プレイヤーと 同じ
- 大きさ（ヒーローと 同じ くらいの 高さ 150px を 1倍として）: 黄金マッチョ・神様・高層ビルマッチョ 1.5倍（225px）、銀のゴリラ 2倍（300px）、巨大筋肉ロボ 3倍（450px）。足もとを 基準に 拡大、どの 動きでも 同じ 大きさ（`js/chara.js` の `ALLY_SIZE`）
- いつも プレイヤーの うしろ（ひだり）。ヒーローの うしろの はしと 仲間の まえの はしの あいだを ヒーロー 0.75体ぶん（約50px）あけ、キャラの はばに あわせて 距離を 変える（ゴリラ・ロボは とおめ）。ふりむいても まえに 回りこまず、さがってきた ときも 重ならない。追従は 速さの 上限つきで なめらかに
- 大きな 仲間は 数字ブロック・アイテム・ヒーローの うしろに 描くので 問題を かくしません（問題カードは いつも いちばん 前）
- 仲間の からだに ふれた **ふつうの れんがブロック**（地形の れんが）は つぶして 進みます。問題の 数字ブロック・石の かべ・ボスは こわせず、正解するまで ヒーローも 仲間も その 手前で 止まります。地面・乗れる 板・ステージの はしは こわしません。れんがを こわしても 正解・ダメージ・点数には なりません
- レア演出の あと プレイヤーの うしろに 加入（加入SE ＋ 本人の セリフ）→ **セリフが 終わってから** ヒーローの 攻撃（攻撃の 音も その とき）→ 壁なら 続いて「パワー全開」。同時に 1体まで。別の レアで 交代、同じ レアなら 1体の まま（あいさつだけ もう一度）。通常キャラが 出ても 消えません
- 正解の たびに **ヒーローの こぶしの あとに 仲間が 追撃**（こぶしの 0.1秒後に 攻撃の 動き → 0.3秒後に 弾）。オトナの ボスは こぶしで 1・追撃が 当たって 1（どちらも 答えを 確定した ときに 決めた ぶんだけ。こぶしで たおしたら 追撃は とりやめて 撃破は 1回）。その 正解で 引いた レアは 次の 正解から 参加（交代した ときは 新しい 仲間が 追撃を 受けもつ）
- 壁は どちらの モードも いままでどおり 1回で こわれます（仲間の 追撃は 演出）
- ステージの 終わり・ゲームオーバー・ステージを はなれる・やりなおしで いなくなります（次の ステージへ 引きつがない）。仲間の ライフ・被弾は ありません
- 仲間の 絵は ステージ開始後、ボスの 絵の あとで 5体ぶん 順に 読みこみます（まだ 読めていない ときは 読めしだい 加入）

### 素材を 作り直す ツール

```
pip install pillow numpy imageio-ffmpeg
python tools/process_muscle.py --fill macho_stampede_4s_fill.mp4 --matte macho_stampede_4s_matte.mp4   # マッスル群を 透過 → assets/video/muscle.mp4・音は assets/sfx/muscle.mp3（等倍・カットなし）
python tools/build_media.py --bgm <「BGM・SE」フォルダ> <素材フォルダ> ... <SE> <音声データ>   # BGM候補の 登録と 音量そろえ・音の コピー（元は source/voice/、前後の 無音を けずった ゲーム用は assets/voice/。仲間・オトナの 声は MP3 に）・js/media.js・元画像の 保管
python tools/build_chara.py <macho_boss_assets> <rare_ally_assets>   # ボス 20体・仲間 5体の 画像を assets/boss/・assets/ally/ へ、js/chara-data.js を 作る
python tools/trim_voices.py                                        # 声の はじまり・おわり の 位置を ひょうじ（けずる 位置の 確認）
python tools/fix_cutin3.py source/cutin/本気の背中と爆発的な文字-3.png source/cutin_edit/本気の背中と爆発的な文字-3_できるぞ.png
python tools/process_cutins.py source/cutin source/cutin_edit [番号 ...]  # 緑背景の 除去 → assets/cutin/（番号を つけると その キャラだけ）
python tools/process_sprites.py マッチョの画像.webp ボスの画像.webp     # キャラの コマ分割
```

確認用の 画像（明るい背景・暗い背景に 重ねた 一覧など）は `tools/out/` に 出ます。
