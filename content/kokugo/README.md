# こくごモードの 物語データ

1ステージ ＝ 1ファイル（物語 1つ ＋ 問題 7問）。レベル1〜5 × ステージ1〜4 で 20ファイルです。
文章・問題・正解は ここの JSON だけで差し替えられます（ゲームのプログラムは触りません）。

```
content/kokugo/level1_stage1.json   … レベル1・ステージ1
content/kokugo/level1_stage2.json
  …
content/kokugo/level5_stage4.json   … レベル5・ステージ4
content/kokugo/TEMPLATE.json        … 記入用テンプレート（ゲームは読みません）
content/kokugo-sample/sample_story.json … 開発・テスト用の仮データ（正式データではありません）
```

いまは 20ファイルとも `"ready": false`（＝物語なし）で、ステージえらびに「じゅんびちゅう」と出て始められません。

## 差し替え手順

1. `TEMPLATE.json` をコピーして、内容を書きかえる
2. ファイル名を `level{レベル}_stage{ステージ}.json` にして、このフォルダの同じ名前のファイルに上書きする
3. ブラウザでゲームを開き、こくごモード → そのレベルを選ぶ
   - カードに物語の だいめい が出れば OK
   - 「データ エラー」と出たら、ブラウザの開発者ツールのコンソールに **ファイル名と場所**（例: `questions[3].choices[1]: 漢字・英字が あります「山」`）が出ます。直して再読み込み
4. 公開する（GitHub に push。反映まで数分かかることがあります。古い表示のときは再読み込み）

内容を直したら `contentVersion` を 1 ふやしてください（どの版か わかるように）。

## 項目の説明

| 項目 | 必須 | 説明 |
|---|---|---|
| `formatVersion` | ○ | データ形式の版。いまは **1** 固定 |
| `storyId` | ○ | 物語の ID（英数字でよい。例 `lv1-st1-kotori`）。表示はされません |
| `contentVersion` | ○ | 内容の版（整数）。直すたびに 1 ふやす |
| `level` / `stage` | ○ | レベル（1〜5）・ステージ（1〜4）。ファイル名と同じにする |
| `title` | ○ | 物語の だいめい（ひらがな・カタカナ）。ステージカードと よむ画面に出ます |
| `pages` | ○ | 本文。文字列の配列。**1つ＝1ページの くぎり**（ここで必ずページが変わります）。<br>1ページの中は 画面の大きさに あわせて 自動で さらに分けます（段落 → 文の順。文字は小さくしません。1ページ 約300文字まで）。<br>段落の あいだは 空行（`\n\n`）、文の くぎりは「。」「！」「？」 |
| `questions` | ○ | 問題。**ちょうど 7問**。じゅんばんに 出ます：1〜4問め＝道中の かべ、5〜7問め＝ボス |
| `questions[].id` | ○ | 問題の ID（例 `q1`）。7問の中で かさならない |
| `questions[].text` | ○ | 質問文（ひらがな・カタカナ） |
| `questions[].choices` | ○ | 選択肢。**ちょうど 3つ**。画面の じゅんばん（1・2・3）＝この じゅんばん |
| `choices[].id` | ○ | 選択肢の ID（例 `a` `b` `c`）。その問題の中で かさならない |
| `choices[].text` | ○ | 選択肢の文（ひらがな・カタカナ。長くても おりかえして ぜんぶ出ます） |
| `questions[].answer` | ○ | 正解の **選択肢の ID**（例 `"b"`） |
| `ready` | | `false` のときは「じゅんびちゅう」（物語なし）。物語を入れたら消すか `true` に |

## 読みこみ時の チェック

次の どれかに あてはまると その ステージは「データ エラー」で始められません（ゲームは止まりません）。

- 本文（`pages`）が ない・空
- 問題が 7問 ではない
- 選択肢が 3つ ではない
- 正解 ID（`answer`）が 選択肢に ない
- 問題 ID・選択肢 ID が かさなっている
- だいめい・本文・質問文・選択肢に **漢字・英字** が ある（ID は チェックしません）
- `formatVersion` が 1 ではない／`storyId`・`title` が ない／`contentVersion` が 整数ではない

記号（「」、。！？・ー）と 数字は つかえます。

## 開発用: 仮データで ためす

URL に `?kokugo=sample` を付けると、全ステージが `content/kokugo-sample/sample_story.json` の物語になります。
（例 `https://yk19890121.github.io/hinatanogame/?kokugo=sample`）正式データには影響しません。
